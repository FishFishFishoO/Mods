# Fish's Mods

Mods for **Eastern Era** by FishFishFish. Thank you for testing!

## Download

Go to **[Releases](../../releases)** (on the right of this page) and download the zip of the mod you want to test. Each zip holds one mod and a short readme.

Please don't use the green **Code → Download ZIP** button. It downloads everything at once and may leave out the large `.pak` files.

## Folders

| Folder | What's in it |
|---|---|
| **Finished Mods** | Tested in game and working. Sorted by type: Characters, Quality of Life, Cheats, Items, Hairs, Profile Pictures Only. |
| **Untested Mods** | Built, but not checked in game yet. **These are the ones I need testers for.** |
| **Unfinished Mods** | Still being worked on. These may not do anything useful yet. |

Character mods come in two versions, **(EN)** English and **(ZH)** Chinese. Install only one of the two.

## How to install a mod

1. Close the game.
2. Unzip, then copy the mod's folder (for example `Stack999` or `wen`) into
   `...\steamapps\common\EasternEra\EasternEra\Content\Mods\`
   (In Steam: right-click Eastern Era → Manage → Browse local files. Make the `Mods` folder if it isn't there.)
3. Start the game and turn the mod on in the Mod List.
4. If you're subscribed to the same mod on the Steam Workshop, turn that copy off while testing.

**Back up your save** before trying anything from Untested Mods or Unfinished Mods.

**Gate Recruit Test** (in Untested Mods) is a testing cheat: press **F8** in game to make a modded character walk up to your sect gate. Remove it when you're done.

## Reporting a problem

Open an **[Issue](../../issues)** (or message me on Discord) with:

- the mod's name and what happened,
- a screenshot if you can,
- the log file: `%LOCALAPPDATA%\EasternEra\Saved\SaveGames\log.txt` (paste that path into the File Explorer address bar),
- if the game crashed: the newest folder in `%LOCALAPPDATA%\EasternEra\Saved\Crashes\`.
